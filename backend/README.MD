# Pokretanje backend servera

## Implementacija
Backend aplikacije više nije potrebno pokretati zbog implementacije na live server Render, stoga za pokretanje lokalno nastavite sa frontend dijelom pokretanja

## 1. Ulazak u folder
```bash
cd backend
```

## 2. Instalacija paketa
```bash
npm install
```

## 3. Pokretanje servera
```bash
npx node src/server.js
```

## 🌐 Backend URL
http://localhost:3000
